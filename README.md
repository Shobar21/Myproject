# FastFood Website

A responsive fast food restaurant website where visitors can browse the menu by category,
learn about the restaurant, read customer reviews and add items to a cart.

**Live demo:** https://myproject-nu-black.vercel.app

## Features

- **Hero section** with an "Order Now" button that jumps to the menu
- **Menu** organized into four categories: Snacks, Food, Drinks and Sweets
- **Search** to find items quickly
- **Shopping cart** page with an item counter in the navigation bar
- **About Us** section
- **Services** section: 24/7 service, free delivery and easy payments
- **Customer reviews** section
- **Contact** details in the footer
- Smooth navigation between sections (Home, Menu, About Us, Services, Reviews)

## Pages and sections

| Page / section | What it shows |
|---|---|
| Home | Welcome banner with a call-to-action |
| Menu | Food items grouped by category |
| About Us | What makes the food special |
| Services | 24/7 service, free delivery, easy payments |
| Reviews | What customers say |
| `cart.html` | Items added to the cart |

## Getting started

No build step is needed.

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
   cd YOUR_REPOSITORY
   ```
2. Open `index.html` in your browser.
   For a better experience, use the **Live Server** extension in VS Code
   (right-click `index.html` and choose **Open with Live Server**).

## Deployment

The site is deployed on Vercel as a static website. To deploy your own copy,
push the project to GitHub, import the repository on Vercel and deploy
(no build command or output directory is needed).

## Customization

- Replace the placeholder text in the About Us and Services sections with your own.
- Replace the sample customer names and reviews with real ones.
- Update the phone number and footer details in the contact section.
